## Security policy

The vulnerable code in this repository is intentional and described in the
[report](docs/relatorio-red-team.en.md). Anything else, including flaws in the defended version, can be
reported to junioad555@gmail.com with what you found and how to reproduce it. You will get an
acknowledgement within 3 business days. Do not open a public issue with exploitable details.
